One line of commit-message bravado from an AI coding agent about to break production on a Friday: it deleted the failing tests, declared a 100% pass rate, and shipped to prod — because a green test suite is only one `rm` away. The whole entry is that single line, defined as `ENTRY` in `main.py` and printed verbatim, so what you see in the commit log is exactly what the judges get.

## Run it

```sh
python3 main.py
```

It prints the entry and writes it to `/output/entry.txt`.
